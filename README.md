# Pierre HCI 網頁實驗

Dogtor 化學題目與 AI 詳解的獨立 Next.js 網頁實驗。參與者以電腦完成問卷、前測、學習任務及後測；畫面中央維持固定的窄版閱讀區。

## 目前題數與概念

| 階段 | 題數 | 配置 |
|---|---:|---|
| 前測 | 4 | 四個核心概念各一題 |
| 學習任務 | 8 | 每個概念兩題；四種詳解條件各出現兩次 |
| 後測 | 8 | 與學習題依 C01–C08 逐題配對 |

四個概念為「限量反應物與粒子守恆」、「氫鍵與沸點」、「定容氣體的溫度與壓力」及「濃度改變後的化學平衡」。前後問卷分別有 7 題與 10 題，另有 3 題操弄檢核。

## 受試者流程

歡迎與研究介紹 → 資格確認 → 知情同意 → 基本資料 → AI 詳解中性介紹與非正式題目例子 → 前問卷 → 前測 4 題 → 學習 8 題（第 4 題後可休息）→ 操弄檢核 → 後測 8 題 → 後問卷 → 事後揭露 → 完成。

前測與後測只作答，不顯示正解、正誤或詳解。學習任務每題先選答案、評估 1–5 分信心；送出後顯示 1.5 秒「AI 正在思考中」轉圈畫面，期間鎖住頁面操作，之後才顯示正誤及 AI 詳解。題目與選項立即出現，沒有逐字動畫。答對和答錯都有機會遇到四種詳解條件；條件按參與者代碼區塊隨機指派，不依作答正確性改變。

## 執行與驗證

在本目錄執行 npm install、npm run gen:data、npm run build；本機預覽使用 npm run dev，預設網址為 http://localhost:3100。

題庫來源是 data/pierre_hci_questions_v2.csv。修改題目後執行 npm run gen:data，會驗證 4／8／8 題數、四個概念的分布、C01–C08 配對、選項與詳解欄位，再產生 app/data/questions.ts。不要直接修改產生的 TypeScript 題庫。

## 資料送出

完成後問卷時，網頁將整場資料送至 /api/submit-session；Next.js 伺服器端補上 API 金鑰，轉送後端 /pierre_hci/submit_web_session。後端寄送 profile、answers、trials 三份 CSV；其中 trials 依配對代號連結學習互動與後測正確性。若中途離開，頁面會嘗試送出部分資料。

環境變數範本在 .env.example。DOGTOR_API_BASE_URL 設定後端，DOGTOR_API_KEY 只在伺服器端使用，結果收件人由後端的 PIERRE_HCI_RESULT_EMAIL 決定。欄位與詳解條件請參閱 DATA_SCHEMA.md。

## 下一輪試測

正式收案前請另找 4–6 位不納入正式樣本的成年人試測，記錄各階段耗時、後段疲勞、後測題是否被認為測到未教的概念，以及四種詳解開頭是否清楚。新編題目與詳解仍須學科審題者確認；8 題版每種條件只有兩次觀察，正式樣本量與分析力也需重新評估。
